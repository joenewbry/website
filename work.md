## Selected public projects

### Inspectable Trust

An experimental protocol for agent-to-agent questions and access negotiation.
Each side uses a plain-language trust.md and a history log to make decisions
inspectable. The repository describes a five-phase session: open, handshake,
grant, work, close. This is a protocol experiment, not a proven guarantee that
an LLM can secure arbitrary private information.

Source: https://github.com/joenewbry/inspectable-trust
